Proceso para Medir las 6 Dimensiones

Cada puntaje se obtuvo mediante la función calculate_quality_dimensions() de data_service.py, evaluando las 12.500 filas del dataset raw. El proceso fue:

  1. Definición de requisitos y umbrales de aceptación: a partir de REQUISITOS_CALIDAD se fijaron el propósito analítico, los usuarios objetivo y el umbral mínimo exigido por dimensión (Completitud ≥ 99%, Exactitud = 100%, Consistencia = 100%, Unicidad = 100%, Validez ≥ 99.5%, Actualidad = 100%).
  2. Operacionalización métrica: cada dimensión se formalizó como una fórmula con numerador y denominador explícitos (ver tarjetas de cada dimensión), evitando evaluaciones subjetivas.
  3. Evaluación fila a fila sobre el dataset:
    • Completitud: celdas no nulas sobre el total de 337.500 celdas.
    • Exactitud: registros donde |Neto − (Bruto − Costos)| ≤ 150 COP (margen de redondeo).
    • Consistencia: registros sin contradicciones lógicas (Régimen Subsidiado con cotización a pensión y ARL; Posgrado con edad < 22).
    • Unicidad: registros libres de duplicidad de clave o fila completa.
    • Validez: registros conformes con dominios (países, niveles), rangos de edad [18,75], jornadas [4h, 88h] y ciudades canónicas.
    • Actualidad: registros con año dentro de la ventana 2021–2026.
  4. Ponderación del DQI: índice compuesto 0.20·Completitud + 0.25·Exactitud + 0.20·Consistencia + 0.15·Unicidad + 0.10·Validez + 0.10·Actualidad (los pesos reflejan la criticidad de cada dimensión para los modelos).
  5. Clasificación del estado: cada dimensión se etiqueta como Excelente / Aceptable / Crítico según su umbral; un DQI por debajo del nivel exigido confirma que el dataset requiere tratamiento antes de minería.
  6. Interpretación: el DQI inicial obtenido es la línea base que se contrastará con el DQI del dataset tratado para validar la efectividad del plan de limpieza.

03 / Justificación Teórica

Marco de Medición de Calidad de Datos

La evaluación de calidad no se limita a contar valores nulos. En Minería de Datos, la Exactitud y la Consistencia son determinantes: un dataset con 0% de nulos pero con contradicciones contables (ingreso neto mayor que el bruto) o inconsistencias legales (trabajadores en Sisbén que cotizan a ARL) distorsionaría por completo los árboles de decisión y los modelos de regresión.
